 ✈️ Airline Data Analysis & Dashboard

 📌 Project Overview

This project focuses on analyzing airline operational data using **SQL and Microsoft Excel** to identify important trends and performance indicators related to flights, passengers, airlines, routes, load factor, and distance groups.

The project combines SQL-based data analysis with an interactive Excel dashboard to transform raw airline data into meaningful business insights.



 🎯 Project Objectives

The main objectives of this project are:

* Analyze overall airline and flight performance
* Calculate total passengers and available seats
* Analyze airline load factor
* Identify passenger trends over time
* Compare airline performance
* Identify high-frequency routes
* Compare weekday and weekend flight performance
* Analyze flights based on distance groups
* Calculate total departures and air time
* Present key findings through an Excel dashboard

 📊 Key Analysis

 Load Factor

Load factor was calculated using:

Load Factor = (Transported Passengers / Available Seats) × 100

The SQL analysis calculates the overall load factor as well as load factor across different time periods and carriers.



 Airline Performance

The analysis compares airlines based on:

 Total transported passengers
 Available seats
 Load factor

Among the analyzed carriers, Southwest Airlines Co. and Delta Air Lines Inc. account for some of the highest transported passenger volumes in the analysis.



Route Analysis

The project identifies routes with the highest number of departures performed.

Examples of high-frequency routes in the analysis include:

* Atlanta, GA → New York, NY
* Kahului, HI → Honolulu, HI
* Hyannis, MA → Nantucket, MA
* Boston, MA → Nantucket, MA


 Weekday vs Weekend

The analysis compares airline load factor between weekdays and weekends.

The results show very similar load-factor performance between the two day types, allowing comparison of passenger utilization across different travel periods.



 Distance Analysis

Flights were also analyzed according to distance groups.

A large proportion of flights fall into the shorter-distance categories, particularly:

 Less than 500 miles
 500–999 miles
 1,000–1,499 miles

This provides an overview of the distribution of short-, medium-, and long-distance flights within the dataset.

 💡 Business Insights

The analysis can help airline management understand:

1. Passenger demand
   Passenger volumes can be used to identify periods and airlines with stronger demand.

2. Capacity utilization
   Load factor helps evaluate how effectively available seating capacity is being utilized.

3. Carrier performance
   Comparing passenger volumes and load factors provides a view of individual carrier performance.

4. Route demand
   High-frequency routes can indicate important travel corridors that may require continued capacity planning.

5. Travel patterns
   Weekday/weekend and monthly analysis can help identify differences in passenger utilization.

6. Distance distribution
   Understanding the number of flights across distance groups can support route and fleet planning decisions.
